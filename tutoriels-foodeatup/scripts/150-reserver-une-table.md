# 150 — Réserve ta table

- Fiche : `reserver-une-table` — Réserver une table (https://tutoriel.foodeatup.com/tutoriel/reserver-une-table)
- Module : client-restaurant · Où tourner : téléphone, côté client (site public, QR de table, page fidélité)
- Durée visée : 45-75 s · Voix : Adam `TGAegA0zNRi8I6nUdq3i`, ElevenLabs `eleven_v4`, une prise

## Accroche (3 premières secondes)
Samedi soir, tu appelles pour réserver… et personne ne décroche.

## Plan de tournage (pour Mouna)
1. Écran de départ : téléphone, site du restaurant, bloc de réservation.
2. Geste : choisir le nombre de personnes, la date, l'heure ; montrer une offre sur un créneau.
3. Geste : remplir nom, téléphone, e-mail ; laisser la case des offres décochée ; réserver.
4. Geste : toucher « Ajouter à mon agenda ».
5. Résultat à montrer 2 s : un créneau complet qui propose la liste d'attente.
