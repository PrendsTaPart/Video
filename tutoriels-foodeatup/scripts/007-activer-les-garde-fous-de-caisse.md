# 007 — Plus de remise sauvage

- Fiche : `activer-les-garde-fous-de-caisse` — Activer les garde-fous de caisse (https://tutoriel.foodeatup.com/tutoriel/activer-les-garde-fous-de-caisse)
- Module : caisse-pos · Où tourner : Configuration boutique › Intégration
- Durée visée : 45-75 s · Voix : Adam `TGAegA0zNRi8I6nUdq3i`, ElevenLabs `eleven_v4`, une prise

## Accroche (3 premières secondes)
« Une remise de trop, un plat offert sans rien dire : le soir, tu ne sais pas qui. »

## Plan de tournage (pour Mouna)
1. Écran de départ : Configuration boutique › Intégration, carte Garde-fous de caisse.
2. Geste : saisir une remise maximale serveur et un plafond titres-restaurant, enregistrer.
3. Geste : sur une note, appliquer une remise au-delà : la caisse demande un responsable.
4. Résultat à montrer 2 s : « Garde-fous enregistrés ✓ ».
5. Plan de coupe : le code personnel d'un responsable tapé sur le pavé.

## Voix off (texte envoyé à ElevenLabs)
[excited] Une remise de trop, un dessert offert sans rien dire… Le soir, impossible de savoir qui. On pose des garde-fous.
Configuration boutique, Intégration, carte Garde-fous de caisse.
Première ligne : la remise maximale d'un serveur. Au-delà, et pour offrir un article, il faut le code d'un responsable.
Deuxième ligne : le plafond des titres-restaurant par ticket. La caisse refuse au-dessus.
Tu peux aussi choisir l'impression automatique du ticket, l'étape « table débarrassée », et le décompte du stock à la vente.
[playful] Ce que tu ne veux pas contrôler, tu le laisses vide. Personne n'est gêné.
Enregistrer. [amazed] « Garde-fous enregistrés ». Regarde : le serveur dépasse, la caisse demande le code. Et c'est le code tapé qui compte, pas la session du patron.
Essaie-le dans ton mode école.

## Sous-titre de fin / appel à l'action

## À vérifier avant de tourner
- Libellés exacts des champs de la carte (remise max, plafond titres-restaurant, étape nettoyage, décompte du stock).
- Le décompte du stock à la vente : vérifier son libellé exact (« stock_deduction_on_sale ») dans la carte.
