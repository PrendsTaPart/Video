## Accroche (3 premières secondes)
Ton réseau grandit… et chaque réglage est éparpillé dans un coin différent.

## Plan de tournage (pour Mouna)
1. Écran de départ : Siège › Configuration du réseau, les tuiles.
2. Geste : ouvrir la tuile du catalogue central.
3. Geste : revenir, ouvrir la politique de prix (mode, coefficient, validation des surcharges).
4. Geste : survoler une tuile grisée pour lire son motif.
5. Résultat à montrer 2 s : le hub complet.
