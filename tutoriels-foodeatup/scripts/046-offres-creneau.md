## Plan de tournage (pour Mouna)
1. Écran de départ : Réservations, onglet promos (?tab=promos).
2. Geste : créer une offre sur un créneau creux, choisir le périmètre (tout ou sélection de plats).
3. Geste : cocher les conditions et « afficher sur le site ».
4. Résultat à montrer 2 s : la section « offres » du site avec le bouton qui présélectionne l'heure.
5. Plan de coupe : en caisse, bandeau « Appliquer l'offre sur N lignes ».

## Voix off (texte envoyé à ElevenLabs)
[excited] Mardi soir, ta salle est vide… Et si une offre la remplissait toute seule ?
Dans Réservations, onglet des promos par créneau. Tu choisis le créneau creux et la remise.
Le périmètre : toute la carte, ou une sélection de catégories, de plats, de formules. Les conditions s'écrivent en clair : hors boissons, pas avec la fidélité, retard maximum.
Tu coches « afficher sur le site ».
[amazed] Sur ton site, une section affiche les offres des prochains jours. Seulement sur les créneaux encore réservables ! Jamais une promesse sur un service complet. Le client clique, l'heure est déjà sélectionnée.
Le jour J, à la caisse, un bandeau te propose d'appliquer l'offre sur les bonnes lignes. Un geste.
[whispers] Le plafond de remise et le code du responsable s'appliquent toujours.
Essaie-le dans ton mode école.
