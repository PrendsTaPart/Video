## Plan de tournage (pour Mouna)
1. Écran de départ : Configuration › Mode école, onglets par section.
2. Geste : lancer une mission (ex. créer un plat avec un prix).
3. Geste : faire l'exercice dans l'école, revenir, la mission se vérifie seule.
4. Résultat à montrer 2 s : le quiz corrigé avec l'explication.
