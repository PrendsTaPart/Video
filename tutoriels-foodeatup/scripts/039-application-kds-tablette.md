## Accroche (3 premières secondes)

## Plan de tournage (pour Mouna)
1. Écran de départ : Cuisine (KDS) › carte Application tablette, bouton pour créer un code d'appairage.
2. Geste : sur la tablette, ouvrir l'application KDS, taper le code à six caractères.
3. Geste : choisir le poste (chaud, froid…), régler les options du poste.
4. Résultat à montrer 2 s : un ticket qui arrive, BUMP pour l'avancer.
5. Plan de coupe : la liste des appareils au back-office (en ligne, batterie, version) et le bouton Révoquer.

## Voix off (texte envoyé à ElevenLabs)
[excited] Les bons papier qui s'envolent devant le four… On passe à la tablette !
Au back-office, Cuisine KDS, carte Application tablette. Tu crées un code d'appairage.
Sur la tablette, tu ouvres l'application KDS et tu tapes le code. [amazed] C'est appairé ! Pas de mot de passe à retenir en cuisine.
Tu choisis le poste : le chaud, le froid, le pass. Les tickets arrivent avec leur source, leurs cuissons, les allergies en évidence.
Un plat est prêt ? Tu le fais avancer d'un toucher.
Au back-office, tu vois chaque tablette : en ligne, sa batterie, sa version. Une tablette perdue ? Révoquer, elle est déconnectée.
[whispers] Le code ne sert qu'une fois. Et la tablette ne voit que ta cuisine.
Essaie-le dans ton mode école.
