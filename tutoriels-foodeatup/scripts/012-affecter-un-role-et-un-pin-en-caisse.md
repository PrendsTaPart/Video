# 012 — Un code par serveur

- Fiche : `affecter-un-role-et-un-pin-en-caisse` — Affecter un rôle et un code PIN à un employé (https://tutoriel.foodeatup.com/tutoriel/affecter-un-role-et-un-pin-en-caisse)
- Module : caisse-pos · Où tourner : Équipe › Employés › fiche › rôle + code personnel
- Durée visée : 45-75 s · Voix : Adam `TGAegA0zNRi8I6nUdq3i`, ElevenLabs `eleven_v4`, une prise

## Accroche (3 premières secondes)
« Un seul code pour toute l'équipe ? Alors personne n'a jamais encaissé personne. »

## Plan de tournage (pour Mouna)
1. Écran de départ : Équipe › Employés › fiche d'un serveur.
2. Geste : lui donner le rôle type « Serveur » et un code personnel.
3. Geste : sur la caisse, écran « Qui prend le service ? », toucher son nom, taper son code.
4. Résultat à montrer 2 s : la barre de service affichant le prénom et l'initiale.
5. Plan de coupe : Équipe › Rôles › Rôles types.

## Voix off (texte envoyé à ElevenLabs)
[excited] Un seul code pour toute l'équipe ? Alors le soir, personne n'a encaissé personne. Chacun son code !
Tu ouvres Équipe, Employés, puis la fiche de ton serveur. Tu lui donnes un rôle. Pas besoin de tout cocher : prends un rôle type, Serveur, Barman, Gérant… Il est prêt.
Ensuite, son code personnel. C'est le même que pour la pointeuse. Un seul code à retenir.
[amazed] Maintenant, sur la caisse : « Qui prend le service ? ». Il touche son nom, il tape son code. C'est lui qui encaisse, lui qui remise, et c'est écrit partout.
[whispers] Clôturer la caisse, c'est une permission. Choisis bien qui fait le Z.
Et un employé ne peut jamais se donner un droit qu'il n'a pas. Même s'il voit la page des rôles.
Essaie-le dans ton mode école.
