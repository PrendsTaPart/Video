# 080 — Tes recettes sur tablette

- Fiche : `application-recettes-tablette` — Application Recettes — appairer une tablette (https://tutoriel.foodeatup.com/tutoriel/application-recettes-tablette)
- Module : configuration · Où tourner : Configuration boutique › Application Recettes
- Durée visée : 45-75 s · Voix : Adam `TGAegA0zNRi8I6nUdq3i`, ElevenLabs `eleven_v4`, une prise

## Accroche (3 premières secondes)
Tes recettes sur une tablette en cuisine, sans câble ni papier.

## Plan de tournage (pour Mouna)
1. Écran de départ : Configuration boutique › Application Recettes.
2. Geste : créer un code d'appairage.
3. Geste : sur la tablette, ouvrir l'application FoodEatUp Recettes et saisir le code.
4. Résultat à montrer 2 s : la tablette qui affiche les univers de recettes ; dans le back-office, la liste des fiches incomplètes et « Compléter ».

## Voix off (texte envoyé à ElevenLabs)
[excited] Ta recette du chef est dans un classeur taché de sauce ? Mets-la sur une tablette. Regarde. Dans Configuration boutique, Application Recettes. Tu crées un code d'appairage. Sur ta tablette, tu ouvres l'application FoodEatUp Recettes et tu tapes le code. C'est relié. [amazed] Tes recettes apparaissent, rangées par univers, avec leurs étapes, leurs minuteurs et leurs vidéos. Ton cuisinier se connecte avec son code personnel, et l'application sait qui cuisine. [playful] Et ici, dans le back-office, tu vois les fiches à compléter : une durée d'étape, une durée de vie qui manque. Tu cliques « Compléter », tu remplis, c'est à jour sur la tablette. Ta brigade suit la même recette, à chaque service.

## Sous-titre de fin / appel à l'action
« Essaie-le dans ton mode école. »

## À vérifier avant de tourner
- Il faut une tablette Android avec l'application FoodEatUp Recettes installée (APK).
- Vérifier que l'offre du restaurant école porte recettes_app (Premiers Pas et au-dessus).
