## Accroche (3 premières secondes)
« Tu es une boulangerie. Pourquoi ta caisse t'ouvre le plan de salle à chaque client ? »

## Plan de tournage (pour Mouna)
1. Écran de départ : caisse, menu Caisse ▾ › Mode par défaut de la caisse.
2. Geste : choisir Comptoir (ou À emporter).
3. Geste : encaisser une vente : la caisse rouvre directement une note comptoir.
4. Résultat à montrer 2 s : après le code personnel, arrivée directe sur une note comptoir.
5. Plan de coupe : Réglages › garde-fous de caisse, même réglage.
