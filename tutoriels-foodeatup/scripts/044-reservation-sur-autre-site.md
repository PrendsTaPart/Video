## Plan de tournage (pour Mouna)
1. Écran de départ : Réservations › Intégration & Google.
2. Geste : choisir un modèle (classique, élégant, minimal, sombre, bistrot), voir l'aperçu à côté.
3. Geste : copier le code du bouton flottant ou de la fenêtre.
4. Résultat à montrer 2 s : le module ouvert sur une page de site de démo.
5. Plan de coupe : le graphique de provenance des réservations.
