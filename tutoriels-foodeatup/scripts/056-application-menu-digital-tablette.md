# 056 — Le menu sur tablette

- Fiche : `application-menu-digital-tablette` — L'application Menu digital sur la table (https://tutoriel.foodeatup.com/tutoriel/application-menu-digital-tablette) — **fiche à créer sur l'Académie**

## Accroche (3 premières secondes)
« Une tablette sur chaque table : la carte, la commande, l'addition. Sans attendre personne. »

## Plan de tournage (pour Mouna)
1. Écran de départ : Display › Bornes & tablettes, Ajouter une tablette de table (nom + table).
2. Geste : sur la tablette, appairer avec le code ; elle s'ouvre sur le menu de sa table.
3. Geste : côté client : accueil avec affiches, suggestions, commande, suivi avec temps estimé.
4. Résultat à montrer 2 s : « Payer sur le terminal » : un serveur est appelé avec le TPE.
5. Plan de coupe : écran grand format : rail des catégories, plats, commande.
