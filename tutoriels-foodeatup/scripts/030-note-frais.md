## Voix off (texte envoyé à ElevenLabs)
[excited] « Vous pouvez me faire une note pour ma boîte ? » Bien sûr. Et sans refaire la vente.
La note est réglée ? Dans le rail d'actions, tu touches Note de frais. Le bouton n'apparaît qu'une fois tout payé.
Tu saisis les coordonnées de l'entreprise du client. Ils étaient plusieurs ? Tu indiques le nombre de parts.
[amazed] La note sort avec le montant, la TVA ventilée, la date, ton restaurant. Figée. Un justificatif propre, sans le détail des plats.
[whispers] Ce n'est pas une nouvelle vente : ton chiffre et ton Z ne bougent pas. Une réédition ? Elle est marquée copie.
Et la fidélité est exclue du montant, pour que la note dise exactement ce qui a été payé.
Pas pour une note d'entraînement, ni une note offerte. Logique !
Essaie-le dans ton mode école.
