# 014 — Prends la commande à table

- Fiche : `prendre-une-commande-en-caisse` — Prendre une commande à table (https://tutoriel.foodeatup.com/tutoriel/prendre-une-commande-en-caisse)
- Module : caisse-pos · Où tourner : Service › Caisse
- Durée visée : 45-75 s · Voix : Adam `TGAegA0zNRi8I6nUdq3i`, ElevenLabs `eleven_v4`, une prise

## Accroche (3 premières secondes)
« Une table de six, des entrées, des plats, des desserts : tout doit partir dans le bon ordre. »

## Plan de tournage (pour Mouna)
1. Écran de départ : plan de salle, table « Libre ».
2. Geste : toucher la table, indiquer six couverts, OUVRIR LA NOTE.
3. Geste : catégorie → plats, vérifier les rangs Entrée / Plat / Dessert.
4. Résultat à montrer 2 s : Envoyer (F8), les lignes passent « Envoyé ».
5. Plan de coupe : la table passe « Occupée » sur le plan avec son montant.
