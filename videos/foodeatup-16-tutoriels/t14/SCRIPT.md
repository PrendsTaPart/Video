# Voir les gagnants — historique

**Fiche** `voir-les-gagnants-historique` · module `marketing-fidelite` · identifiant de série `t14`

> Savoir ce que la roue a réellement rapporté.

⚠️ **Film sans rush.** Ce tutoriel n'a pas de capture d'écran : il est en motion
design assumé. Aucun plan ne prétend montrer le produit — une planche
schématique dit « voici l'étape et ce qui compte », là où une fausse interface
prétendrait « voici l'écran ». Le jour où le rush existe, le film est remplacé ;
ce script, lui, reste.

## À quoi ça sert (texte de la fiche)

Une roue cadeaux se juge sur deux chiffres, et ce ne sont pas les lancers : les contacts captés, et les lots effectivement retirés. Un lot gagné qui n'est jamais venu au restaurant n'a rien rapporté.

## Marche à suivre (texte de la fiche)

1. Ouvrez la roue : son statut, ses lancers, ses contacts captés.
2. Lisez les statistiques : lancers, lots gagnés, leads. Le rapport entre les deux premiers dit si la roue est trop généreuse.
3. Passez aux bons émis : actifs, utilisés, expirés.
4. Ce sont les bons utilisés qui mesurent le retour — pas les lots gagnés.
5. Un taux d'expiration élevé signale un lot peu désirable, ou une durée de validité trop courte.

## Astuce du chef

Comparez toujours les bons utilisés aux contacts captés, jamais aux lancers. Le lancer est gratuit pour le client ; c'est le déplacement qui coûte, et c'est lui qu'on mesure.
