Commander à table avec un QR code : comment ça marche

Pas d'appli, pas d'attente, et pas de commande à distance. · Épisode 89 du journal « Mon quotidien d'entrepreneur avec l'IA » · mot-clé TABLE

1Scanner le QR code

Le client scanne le QR code de sa table : la carte s'ouvre dans son téléphone, sans appli à installer.

2Un espace par table

Chaque table a son propre espace de commande.

3Le code de la table

Les amis de la table tapent le même code pour commander ensemble ; la commande part en cuisine.

4Sans code : refusé

Quelqu'un qui n'est pas à table ne peut pas commander pour elle : sans code, la commande est refusée.

5Addition payée : code mort

Une fois l'addition payée, le code ne sert plus. Le paiement passe par un prestataire, et tout est chiffré.
