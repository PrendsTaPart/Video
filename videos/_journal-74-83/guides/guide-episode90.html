Le test : peut-on pirater une commande à table ?

Le test fait pas à pas, comme un client malin. · Épisode 90 du journal « Mon quotidien d'entrepreneur avec l'IA » · mot-clé SÉCURITÉ

1Comprendre la commande

On regarde d'abord comment la commande circule entre la table, le restaurant et la cuisine.

2Un code à usage unique

La table reçoit un code à usage unique quand le restaurant l'accepte.

3Deviner le code

Trois mauvais essais, et on est bloqué.

4Photographier le QR code

Le code meurt dès que la note est payée : la photo ne sert plus à rien.

5Le Wi-Fi public

Sur un Wi-Fi public, personne ne voit le contenu : tout est chiffré.
Un test n'est pas une garantie absolue : la sécurité se revérifie à chaque nouvelle version.
