# Épisode 52 — sources du comparateur

- **Hermès (Hermes Agent, Nous Research)** : open source (MIT), gratuit, crée des compétences à partir de ses tâches, tourne sur ta propre infrastructure → à installer et configurer soi-même. PyPI `hermes-agent`, documentation.
- **Agent ChatGPT (OpenAI)** : rien à installer, s'exécute dans l'environnement d'OpenAI ; les guides d'usage recommandent de relire avant tout usage en production.
- **OpenClaw** : audit Koi Security (février 2026) du registre ClawHub : 341 compétences malveillantes sur 2 857 auditées (≈ 12 %, « une sur dix » au pic). Les compétences signalées ont depuis été retirées et un scan VirusTotal a été ajouté.
- **Muse (Meta)** : agent personnel lancé le 8 septembre 2026, adultes, États-Unis uniquement pour l'instant.
- Grok, cité dans la vidéo de référence, a été retiré faute de source vérifiable.
