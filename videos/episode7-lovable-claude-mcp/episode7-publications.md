## LinkedIn (profil Michael)
J'ai connecté Lovable à Claude. Et ça a changé ma façon de développer mes MCP.

Avant, je développais mes applications dans Lovable, puis je passais d'un outil à l'autre pour retrouver le code, préparer les intégrations et brancher mes agents IA.

Aujourd'hui, Claude retrouve mes projets Lovable, lit leur code, analyse l'historique des modifications… sans rien toucher tant que je ne l'autorise pas.

Test réel sur BraindCode Plugins :
→ 58 outils MCP, 41 en lecture, 17 en écriture
→ un fichier par outil, des paramètres typés, des droits vérifiés à chaque appel
→ en lecture, le serveur renvoie le vrai catalogue
→ sans jeton, il répond 401 : accès refusé

Et tout ne vient pas de Lovable : RapidoRH expose son MCP depuis Laravel.

Deux connexions, deux rôles :
A. Développer : moi → Claude Code → connecteur Lovable → projet → code et tests
B. Travailler : Claude → MCP métier → application → données et actions autorisées

Je ne construis pas seulement des logiciels pour les humains. Je construis aussi les outils qui permettront à mes agents IA de travailler avec eux.
