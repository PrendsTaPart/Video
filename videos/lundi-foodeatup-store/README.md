## Ce que j'ai trouvé (et pas trouvé) sur le module Extensions

J'ai cherché des traces du travail du lundi 26 octobre 2026 partout où j'ai accès :

| Source | Résultat |
|---|---|
| 6 dépôts clonés (4 apps, Video, growth-loop-academy) | Commits du 26/10 : vidéos et animations des sites des 4 apps, décor Blender du jeu. **Aucun Store, aucune Extension.** |
| 19 dépôts GitHub FoodEatUp du compte | Aucun n'a reçu de push le 26/10, hormis les 4 apps. Pas de dépôt Store ou Extensions. |
| Google Drive | Seuls les 4 APK ont été modifiés le 26/10. |
| Lovable (espaces de travail FoodEatUp et BraindCode) | Aucun projet Store ou Extensions FoodEatUp. Le seul « BraindCode Extensions Hub » est une marketplace de prompts, sans rapport. |
| Gmail (Soulayma, extensions, Store, 4 derniers jours) | Aucun résultat. |
| foodeatup.com | `/store`, `/extensions`, `/marketplace` répondent 404. Le module vit sans doute dans le back-office authentifié, auquel je n'ai pas accès. |

**Conséquences dans la vidéo :**
- Le Store est une **maquette conceptuelle**, signalée en permanence à l'écran (« Maquette conceptuelle · module en développement »). Ses cartes contiennent les vraies captures des applications.
- Chaque bouton porte « Bientôt ». L'activation est marquée « pas encore disponible ».
- La scène avec Soulayma n'invente ni réunion, ni conversation, ni image d'elle. Elle illustre les trois étapes que ta voix décrit (parcours, organisation, intégration), sous la mention « Illustration du travail ». Son nom n'apparaît que dans ta voix off et dans les titres.
- L'écosystème est présenté comme une « Architecture conceptuelle ».
- Deux points du brief ne sont pas repris parce qu'ils sont faux à ce jour :
  - le **paiement NFC** de la caisse est « Bientôt », désactivé dans le code ;
  - les **sondages** sont dans l'app Fidélité, pas dans le Menu digital.

  Le rappel de dimanche dit seulement « quatre applications Flutter et le jeu vidéo ».

**À remplacer dès que tu les as** (même minutage) : les captures ou un enregistrement d'écran du vrai module Extensions (scènes 2 et 4), et un élément de travail avec Soulayma, **avec son accord** (scène 3). Envoie-les-moi et je refais le rendu.

## Voix off finale

Voix ElevenLabs « Noé – Content Creator », la même que dimanche pour la continuité. Ce n'est pas ta voix.

> Hier, dimanche, je vous montrais les quatre applications Flutter et le jeu vidéo qu'on a développés pour FoodEatUp. Mais ce matin, une nouvelle idée : et si toutes ces applications étaient accessibles directement depuis FoodEatUp ?
>
> L'objectif, c'est simple : transformer FoodEatUp en une plateforme où chaque restaurateur peut choisir les applications dont il a réellement besoin.
>
> Aujourd'hui, avec Soulayma, on s'est attaqués à cette nouvelle fonctionnalité : imaginer le parcours utilisateur, organiser les extensions, et préparer leur intégration directement dans FoodEatUp.
>
> Demain, un restaurant pourra retrouver ses outils au même endroit : la fidélité, le HACCP, la caisse mobile, le menu digital… mais aussi de nouvelles applications et des extensions intelligentes.
>
> Et le plus intéressant, c'est que ces applications ne sont pas pensées comme des outils isolés. Elles s'inscrivent dans le même écosystème FoodEatUp, avec des fonctionnalités métier et des connexions MCP. L'IA ne sert pas seulement à développer des applications plus vite : elle permet aussi de repenser la manière dont on construit tout un écosystème logiciel.
>
> Dimanche, on construisait les applications. Lundi, avec Soulayma, on construit la plateforme qui permettra de les retrouver au même endroit. Le FoodEatUp Store arrive bientôt. Et ce n'est que le début.

J'ai ajouté une seule phrase au texte du brief : le message à retenir (« L'IA ne sert pas seulement… »), placé à la fin de la scène écosystème.

## Reconstruire

`composition.html` lit le dossier `a/` : les mêmes captures que `../dimanche-4-apps-1-jeu/` (voir son `scripts/preparer-assets.sh`). Ensuite :

```bash
node scripts/render.js frames 0 2670   # (servir le dossier en http sur le port 8778, composition.html → index.html)
```

Puis le mixage avec `scripts/mix-89s.ffmpeg.txt`, et l'incrustation avec `ffmpeg -vf ass=sous-titres/sous-titres-lundi-fr.ass`.
