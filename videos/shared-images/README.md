# Librairie d'images partagée — vidéos FoodEatUp

Images 3D cartoon (style Pixar, fond off-white #F7F9FC, accents bleu #1E9BF0)
réutilisables entre les vidéos du studio. Générées via RapidoCMS.

## brand/
- `foodeatup-logo-mascot.png` — logo FoodEatUp complet (mascotte + wordmark)
- `foodeatup-mark-eight.png` — symbole seul

## characters/
- `equipe-tablette.png` — serveur + chef + serveuse autour d'une tablette
- `chef-robot-highfive.png` — chef qui tape dans la main d'un robot IA
- `commerciale-chef.png` — commerciale + chef présentant un dashboard laptop
- `haccp-paperwork.png` — chef débordé par la paperasse HACCP (classeurs, relevés)
- `chef-fridge-temp.png` — chef + tablette devant une chambre froide inox (relevé T°)
- `chef-claude-assistant.png` — chef qui commande un assistant IA (bulle chat + tablette)
- `chef-kitchen-calm.png` — chef serein, bras croisés, cuisine pro impeccable
- `planning-chaos.png` — chef débordé par le planning (tableau créneaux, calendriers, réveils)
- `chef-planning-board.png` — chef présentant une grille de planning d'équipe (avatars/jours/créneaux)

Pour utiliser dans un projet : copier le PNG voulu dans `<projet>/public/`
(les chemins d'assets HyperFrames sont relatifs à la racine du projet).
