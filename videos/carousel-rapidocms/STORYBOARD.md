# Storyboard — Vidéo de présentation du Carousel RapidoCMS

Format 1080×1920. Fond de marque : blanc cassé + triangles pâles + nuages bleu ciel en coin.
Bandeau haut permanent : logo RapidoCMS (origami) + wordmark. Bas : pastilles de progression
type carrousel Instagram (7 points) + URL `cms.rapidosoftware.com`.
Chaque slide du carrousel entre par un **swipe horizontal** (glissé droite→gauche) + léger zoom,
comme si on feuilletait le carrousel sur un téléphone. Sous-titres incrustés synchronisés à la VO.

## Notes de production
- **Transitions** : glissé horizontal (`slide left`) entre chaque slide, 0,45 s, pour l'effet « feuilletage ».
- **Progression** : 7 pastilles en bas ; la pastille active passe en bleu ciel plein.
- **Sous-titres** : incrustés, blanc sur pastille bleu ciel translucide, ~4 mots/ligne.
- **BGM** : nappe légère et positive (−18 dB), fade in/out.
- **Palette** : accent `#29A9F2`, texte `#1B2A41`, fond `#F7F9FC`.
