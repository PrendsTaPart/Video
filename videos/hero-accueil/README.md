# Vidéo héros de l'accueil (HyperFrames)

Boucle muette de 16 s pour le héros de michael.foodeatup.fr : « Tout ce que vous voyez ici est né sur mon téléphone. »
Écrans réels des projets, logos officiels, photo d'entrepreneur de Michael. Le téléphone (format Note 10, sans logo de marque) est dessiné en CSS.

- `index.html` : version 1920x1080 → `hero-accueil-1920x1080.mp4`
- `mobile/index.html` : version 1080x1920 → `hero-accueil-1080x1920.mp4`
- Rendu : `npx hyperframes render -o <fichier>.mp4` (CLI épinglé 0.8.223)
