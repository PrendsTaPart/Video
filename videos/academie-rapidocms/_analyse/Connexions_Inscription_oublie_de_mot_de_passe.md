## 3. Éléments d'interface relevés

- **Menu latéral** : aucun. Toute la vidéo se déroule sur les écrans d'authentification, hors application.
- **Écrans / cartes** : « Accéder à mon compte », « Mot de passe oublié », « Créer un compte ».
- **Champs de formulaire (libellés / textes indicatifs exacts)** :
  - Connexion : champ e-mail (icône enveloppe, valeur « mikakebail@gmail.com »), champ mot de passe (icône cadenas, valeur masquée).
  - Mot de passe oublié : champ e-mail avec l'exemple « Exemple@gmail.com ».
  - Créer un compte : « Nom du gérant », « Prénom du gérant », e-mail, mot de passe, « Confirmer mot de passe ».
- **Boutons d'action** : « Se connecter », « Envoyer le lien de réinitialisation », « Suivant », bouton rond Google « G ».
- **Liens** : « Mot de passe oublié? » (sans espace avant le point d'interrogation), « créer un compte », « s'identifier ».
- **Textes de liaison** : « vous n'êtes pas encore client? », « vous avez un compte? », séparateur « OU ».
- **Icônes remarquables** : enveloppe (e-mail), cadenas (mot de passe), silhouette (nom/prénom du gérant), logo Google « G », deux arcs de cercle bleus décoratifs en fond.
- **États / statuts** : survol des boutons (éclaircissement), curseur main sur les éléments cliquables. Aucun message de confirmation, aucune erreur, aucune fenêtre modale, aucune notification.

## 4. Ce que le tutoriel enseigne réellement

Le parcours métier complet est : (1) arriver sur la page « Accéder à mon compte » ; (2) saisir son e-mail et son mot de passe puis cliquer « Se connecter » ; (3) alternative : se connecter en un clic avec le bouton Google « G » ; (4) en cas d'oubli, cliquer sur « Mot de passe oublié ? », saisir son e-mail, cliquer « Envoyer le lien de réinitialisation » et suivre le lien reçu par e-mail pour définir un nouveau mot de passe ; (5) si l'on n'a pas encore de compte, cliquer « créer un compte », renseigner Nom du gérant, Prénom du gérant, e-mail, mot de passe et confirmation, puis cliquer « Suivant ».

Ce qui manque ou reste confus dans la capture : aucun clic n'est réellement effectué, on ne voit que des survols ; le tableau de bord promis à 14 s n'apparaît jamais ; la connexion Google n'est pas démontrée (bouton jamais survolé) ; le clic sur « Mot de passe oublié ? » n'est pas montré alors que l'écran change quand même ; l'e-mail de réinitialisation et l'écran « nouveau mot de passe » ne sont pas montrés ; les champs Nom, Prénom et Confirmer mot de passe du formulaire d'inscription restent vides pendant toute la démonstration ; l'écran de suite après « Suivant » (et le « votre espace RapidoCMS est prêt ») n'existe pas à l'image. Les transitions entre les trois cartes sont des coupes sèches, sans clic visible.

Écran figé : les 12 dernières secondes (48 s → 60 s) restent sur le même formulaire d'inscription immobile. Aucun défilement de page n'a lieu dans cette vidéo.
