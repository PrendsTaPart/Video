## 3. Éléments d'interface relevés

Menu latéral gauche : « Tableau de bord » ; **CMS** : « Calendrier », « Historique » ;
**Communication** : « Réseaux sociaux », « Campagne » ; **Editeur** : « Templates » (actif),
« Carte digital », « Bibliothèque », « Prompts ».

Galerie :
- Bouton déroulant « Filtre : Tout »
- Panneau « Filtre de prompt » avec boutons radio « Date(asc) », « Date(desc) », « A_Z », « Z_A »
  (+ une cinquième option masquée par le curseur) et bouton « Appliquer »
- Champ de recherche « Chercher une page »
- Titre « Proposition de thème de Cartes NFC pour vous »
- Vignettes : nom du modèle, auteur « Deker », bouton « Choisir ce modèle »
- Modèles visibles : « Support NFC Instagram », « Support NFC FoodEatUp », « Carte NFC FoodEatUp »,
  « Carte NFC Instagram », « Carte NFC Facebook », « Support NFC Facebook »

Fenêtre modale :
- Titre « Acheter un template »
- Badge « Gratuit » (vert)
- Nom du template, « Description : », « Tag »
- Bouton « Utiliser ce template », croix « × »

Éditeur (« Editeur-Personalisation ») :
- Sélecteur d'aperçu bureau / tablette / mobile
- Barre d'outils : cadre, aperçu (œil), plein écran, code « </> », annuler, rétablir, télécharger,
  corbeille, image, autres icônes, pinceau, engrenage, calques, bouton « + » rose
- Panneau droit : sections repliables « Qr code », « Cartes », « Basic »
- Blocs disponibles : « Qr code », « Support 453e45… », « Carte 1004é6… », « Quote »,
  « Text section », « Text », « Image » (+ deux blocs supplémentaires non légendés lisiblement)
- Étiquettes de sélection sur le canevas : « Div », « Image »

Éléments de la carte NFC modèle : logo du réseau social, mot-symbole « Instagram »,
pictogramme « tap NFC », titre « Suivez-nous », identifiant « @foodeatup », QR code.

Types de gabarits : « Support NFC » (format vertical/paysage grand) et « Carte NFC »
(format carte), déclinés par réseau ou par marque (Instagram, Facebook, FoodEatUp).

## 4. Ce que le tutoriel enseigne réellement

Parcours à refaire :
1. Aller dans « Editeur » → « Templates » et se placer sur la galerie « Proposition de thème de
   Cartes NFC pour vous ».
2. Éventuellement trier la galerie avec « Filtre : Tout » → « Filtre de prompt »
   (« Date(asc) », « Date(desc) », « A_Z », « Z_A ») puis « Appliquer ».
3. Repérer le modèle voulu selon le réseau ou la marque : Instagram, Facebook, FoodEatUp,
   en distinguant les « Support NFC » des « Carte NFC ».
4. Cliquer sur « Choisir ce modèle ».
5. Lire la fiche dans la fenêtre « Acheter un template » : prix (« Gratuit »), description, « Tag ».
6. Cliquer sur « Utiliser ce template ».
7. Dans « Editeur-Personalisation », modifier les textes (« Suivez-nous », « @foodeatup »),
   remplacer le logo (bloc « Image »), ajuster le QR code, et ajouter des blocs depuis le panneau
   droit (« Qr code », « Cartes », « Basic »).

Étapes manquantes ou confuses : le menu « Filtre de prompt » est ouvert puis refermé sans
explication ni effet visible, et son libellé (« prompt ») ne correspond pas au contenu filtré
(des templates) — c'est le passage le plus déroutant de la capture. Aucune modification réelle
n'est effectuée : ni saisie de texte, ni changement de couleur, ni upload de logo, alors que la
voix off les annonce toutes. Le QR code n'est jamais configuré (on ne voit pas où saisir le lien
qu'il doit pointer), ce qui est pourtant le cœur d'une carte NFC. La partie « NFC » elle-même
n'est jamais expliquée : rien ne montre comment associer le visuel à une puce NFC. Enfin, il n'y
a ni enregistrement, ni export, ni commande. L'écran reste figé de 8 s à 28 s.

## 5. Repères de montage

- **Durée totale** : dernière bande de sous-titre à 66 s, dernière image à 64 s → environ **68 s**.
- **Moments forts / chapitres proposés** :
  - 0 s — La galerie « Proposition de thème de Cartes NFC pour vous ».
  - 4 s — Le panneau « Filtre de prompt » (tri des modèles).
  - 20–28 s — Le catalogue par usage : Instagram, FoodEatUp, Facebook.
  - 40 s — Le clic sur « Choisir ce modèle ».
  - 44 s — La fiche « Acheter un template » : « Gratuit », description, « Tag ».
  - 52 s — Ouverture dans « Editeur-Personalisation » (carte Instagram avec QR code).
  - 56 s — Sélection du logo (bloc « Image »).
  - 64 s — Le panneau droit et sa bibliothèque de blocs (« Qr code », « Cartes », « Basic »).
- **Passages sans intérêt (à couper ou accélérer)** :
  - 8–24 s : quatre images quasi identiques, écran figé, curseur qui erre sans clic.
  - 28–40 s : défilement lent de la page, trois images pour montrer la même grille.
  - 44–48 s : la modale reste ouverte sans action.
  - 60 s : image sans sélection ni mouvement, entre deux démonstrations.
- **Image la plus parlante pour la vignette** : **t014 (52 s)** — la carte NFC Instagram ouverte
  en grand dans « Editeur-Personalisation », avec le QR code, le pictogramme NFC et le panneau
  d'outils : elle résume à elle seule le sujet du tutoriel. Alternative : **t001 (0 s)** pour la
  vue catalogue des six modèles NFC.
