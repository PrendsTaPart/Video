## 3. Éléments d'interface relevés

- **Onglets de la page Profil** : « Profil » (actif), « Entreprise », « Configuration compte ».
- **Barre d'outils en haut à droite** : deux icônes de synchronisation/rafraîchissement, pastille de crédit « 605.00€ » (icône carte bancaire), sélecteur de compte « Michael KEBA… » avec chevron déroulant.
- **Titres de carte** : « Paramètre du profil » ; sous-titre « Modifier votre profil admin ».
- **Champs de formulaire (libellés exacts)** : « Nom », « Prénom », « Email », « Numéro », « Adresse », « Code postal », « Photo de Profil ».
- **Textes indicatifs des champs vides** : « Entrer un numéro », « Entrer une adresse », « Entrer un code ».
- **Valeurs affichées** : Nom « KEBAIL-ALI », Prénom « Michael », Email « mikakebail@gmail.com ».
- **Zone d'upload** : cadre en pointillés bleus, icône nuage avec flèche montante, texte « Sélectionner un fichier », bouton « Parcourir ». Vignette d'aperçu sous la zone (icône image grisée, aucune photo chargée).
- **Boutons d'action** : « Parcourir », « Modifier ✎ » (bouton bleu avec icône crayon).
- **Navigation** : flèche retour « ‹ » à gauche du titre « Profil ».
- **États / statuts** : survol bleu plein sur « Parcourir », survol éclairci sur « Modifier ». Aucun message de confirmation, aucune fenêtre modale, aucun sélecteur de fichier système visible.
- **Absents de la capture alors que le titre les annonce** : les onglets « Entreprise » et « Configuration compte » ne sont jamais ouverts.

## 4. Ce que le tutoriel enseigne réellement

Le parcours à refaire : (1) ouvrir la page « Profil » ; (2) rester sur l'onglet « Profil » ; (3) vérifier / corriger « Nom » et « Prénom » ; (4) contrôler l'« Email » ; (5) renseigner le « Numéro », l'« Adresse » et le « Code postal » si on le souhaite ; (6) faire défiler jusqu'au bloc « Photo de Profil », cliquer sur « Parcourir », choisir une image et l'importer ; (7) cliquer sur « Modifier ✎ » pour enregistrer.

Ce qui manque ou est confus : **le titre annonce « et de la fiche entreprise » mais l'onglet « Entreprise » n'est jamais ouvert** — ce contenu est en réalité traité dans la vidéo « Configuration du fiche entreprise ». Aucun champ n'est réellement rempli pendant la démonstration : Numéro, Adresse et Code postal restent vides du début à la fin. La sélection de l'image n'est jamais montrée (pas de fenêtre de fichiers, la vignette d'aperçu reste vide). Le clic sur « Modifier » ne produit aucun message de confirmation à l'écran, alors que la voix off promet une mise à jour « instantanée ». La voix off passe directement du nom/prénom (12 s) à l'adresse (20 s) sans commenter Email ni Numéro.

Rythme : le défilement de la page se fait d'un coup entre 16 s et 20 s (t005 → t006), sans transition douce, et il faut le ralentir ou le remplacer par un scroll animé. L'écran est totalement figé de 44 s à 56 s.

## 5. Repères de montage

- **Durée totale** : environ 62 s (dernier sous-titre à 60 s ; les images s'arrêtent à 56 s, l'échantillonnage se faisant toutes les 4 s. ffprobe indisponible pour confirmer).
- **Moments forts (chapitres proposés)** :
  1. 0 s — Arrivée sur la page « Profil » et présentation des trois onglets.
  2. 8 s — Les champs d'identité : « Nom », « Prénom », « Email ».
  3. 20 s — Défilement vers les coordonnées : « Numéro », « Adresse », « Code postal ».
  4. 26 s — Le bloc « Photo de Profil ».
  5. 32 s — Clic sur « Parcourir » pour importer l'image.
  6. 44 s — Clic sur « Modifier ✎ » pour enregistrer.
- **Passages sans intérêt (à couper ou accélérer)** :
  - 4 s → 8 s : écran identique, curseur qui dérive à gauche.
  - 12 s → 20 s : 8 s d'écran figé avec deux bandes de sous-titre vides (t004, t005) — à couper franchement.
  - 24 s → 28 s : hésitation de souris sans action.
  - 36 s → 44 s : retour à l'état neutre après le survol de « Parcourir », rien ne se passe.
  - 48 s → 56 s : 8 s d'écran figé en fin de vidéo — à couper.
- **Image la plus parlante pour la vignette** : **20 s (t006)** — vue complète de la carte profil avec les six champs, la zone « Photo de Profil » et le bouton « Modifier ✎ » visibles ensemble dans le même cadre.
