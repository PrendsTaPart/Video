## Ce que montre réellement la capture

Le titre du fichier source annonce la création de posts pour les réseaux
sociaux : **il ne s'agit pas de cela**. Rien n'est dit ni fait sur la rédaction
d'une légende, le choix d'un réseau ou la planification. Ce qui est filmé, c'est
la galerie de templates et l'éditeur de personnalisation :

- la grille « Proposition de thème de Poste pour vous », avec ses cartes
  (« Produit Casque écouteurs », « Produit Canapé », « Produit Drone »,
  « Produit Caméra », « Produit Sneakers »), le filtre, la recherche et le
  bouton « Choisir ce modèle » ;
- la fiche du modèle qui s'ouvre par-dessus, avec le badge vert « Gratuit »,
  la description, les tags et le bouton « Utiliser ce template » ;
- l'éditeur de personnalisation : aperçus bureau / tablette / mobile, barre
  d'outils, canevas, et à droite les formats de poste puis les blocs « Quote »,
  « Text section », « Text », « Image ».

**Aucune modification n'est réellement effectuée** : on voit une sélection de
bloc (cadre bleu), rien de plus. Aucun enregistrement, aucun export, aucune
publication. Le statut « premium » n'apparaît jamais : seul le badge « Gratuit »
est visible, et c'est le seul cité. Les intégrations d'IA annoncées par la voix
d'origine ne sont jamais montrées : elles ne sont pas mentionnées.

Le titre de la page d'édition comporte des fautes d'accent et d'orthographe :
les mots sont prononcés correctement, sans être soulignés.

Temps morts écartés du montage : 0 s → 16 s (page strictement identique),
24 s → 28 s, et 56 s → 79 s (l'éditeur ne change plus, fin abrupte). Les
extraits sont pris dans 16–24 s, 28–56 s.

## Carte Version Minute

- **Prompt** : « Enregistre ce visuel comme template de post réutilisable, nommé Promo produit fond sombre. »
- **Outil** : `create_post_template`
- **Suite citée** : `create_draft_tool` pour réutiliser le modèle dans un post.

## Vignette

Timecode 28 s : la fiche du modèle ouverte — le visuel produit, le badge
« Gratuit », la description et le bouton d'action sur une seule image.

## Astuce retenue pour la fiche

Fixer le format du visuel avant de retoucher les textes : changer de dimensions
après coup oblige à repositionner chaque bloc de la mise en page.

## Cas d'usage

- Un gérant veut un visuel de promotion propre sans savoir dessiner.
- Une équipe cherche un modèle calibré pour Instagram plutôt qu'un format au hasard.
- Un utilisateur veut comprendre ce que contient un template avant de l'ouvrir.
