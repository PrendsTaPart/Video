# Tutoriels vidéo — application FoodEatUp HACCP

8 tutoriels (≈ 18 s, 1920×1080) montés avec HyperFrames à partir des vrais écrans de l'application.
Voix : ElevenLabs Adam (`TGAegA0zNRi8I6nUdq3i`), modèle `eleven_v4`, une seule prise.

- `tutos.py` : titres, écrans, étapes et texte de la voix.
- `generer.py` : construit un projet HyperFrames par tutoriel.
- `rendre.sh` : rend chaque projet puis ré-encode (`sortie/<cle>.mp4` + vignette `.jpg`).

Les vidéos sont publiées sur l'Académie (tutoriel.foodeatup.com, module HACCP, section « Application mobile »).
