# Plani't — Fiches personnage (Reference Elements Higgsfield)

Inventaire des character sheets générées pour les 5 personas humains de la série (voir
`references/planit-brand.md` §Personas). Chaque fiche est générée **une seule fois**,
enregistrée comme *Reference Element* dans Higgsfield, puis réutilisée dans tous les
prompts Seedance 2.5 du persona. Règle du dépôt : Claude ne génère jamais sur Higgsfield —
ce fichier documente des fiches déjà produites par l'utilisateur, il n'en crée pas.

## `PH-DIR` — Karim, dirigeant de petite entreprise

- **Statut** : générée par l'utilisateur (image reçue le 2026-08-22), **conforme** au
  prompt de `01-PROMPTS-HIGGSFIELD-SEEDANCE-2.5.md` §3 — trois angles côte à côte (face,
  trois-quarts, profil), fond gris neutre, chemise bleu clair sans logo col ouvert manches
  retroussées, chino anthracite, montre acier au poignet gauche.
- **Fichier dans le dépôt** : ⚠️ **pas encore déposé**. L'image a été envoyée collée
  directement dans la conversation ; dans cet environnement, Claude Code n'a accès qu'à un
  aperçu visuel de ce type d'image, pas à ses octets bruts, donc elle n'a pas pu être
  écrite sur disque ni committée. **Pour l'enregistrer réellement dans le dépôt**, il faut
  la fournir par un canal qui expose un fichier : pièce jointe/upload (comme le zip
  `524d430a-files.zip` de cette session), un lien Google Drive, ou un chemin déjà présent
  sur le disque de la session. Emplacement cible une fois reçue :
  `videos/shared-images/planit/ph-dir-karim.png` (à créer), puis mise à jour de cette fiche
  avec un Reference Element ID une fois enregistrée côté Higgsfield par l'utilisateur.
- **Reference Element ID (Higgsfield)** : à renseigner par l'utilisateur après import dans
  l'interface Higgsfield.
