# Importer un fichier Excel entreprise

Module **Crm** · V02 · `06-importer-un-fichier-excel-entreprise`

## Hook

> Trois cents entreprises dans un tableur. Et une fiche à créer, une par une.
> Un fichier, un bouton, et la liste est là.

**Alternatives proposées :**
1. Votre base clients existe déjà. Elle est juste dans le mauvais outil.
2. Recopier un tableur à la main, c'est une soirée perdue.
3. Vos clients sont dans Excel. Votre CRM, lui, est vide.

## Intro

On part de la page Clients, et on ressort avec toutes vos entreprises dedans. Une fenêtre, un fichier Excel, et c'est fini. Le logiciel vous donne même le modèle à remplir, pour que les colonnes tombent au bon endroit du premier coup.

## Démo

### 1. Ouvrir la page Clients

_0.3s → 2.4s · 4 mots · ~1.6s_

Votre liste de clients.

### 2. Ouvrir la fenêtre d'import

_2.4s → 7.5s · 10 mots · ~4.0s_

La fenêtre d'import. Le modèle à remplir est juste dessous.

### 3. Choisir le fichier et importer

_7.5s → 12.5s · 6 mots · ~2.4s_

On choisit son fichier, on importe.

### 4. Retrouver les entreprises importées

_15.5s → 20.9s · 11 mots · ~4.4s_

Et elles sont là, avec leur ville et leur code postal.

## Faites-le avec Claude

**Faites-le avec Claude**

Votre base est remplie. Pour vérifier ce qui est entré sans faire défiler la page, RapidoCRM se branche sur Claude : vous écrivez votre demande en français, il lit vos données et vous répond. Copiez ce prompt, collez-le, et remplacez ce qui est entre crochets par le nombre voulu.

```
Liste-moi mes [nombre] dernières entreprises avec leur ville et leur code postal.
```

Résultat affiché : **Vos entreprises** — Le fleuriste — lyon, 69002 · Pain d'or — villeurbanne, 69100 · Le fournil saint-jean — lyon, 69005
